## Coupled G2c/G2d/G2e contract

`desired_manifest_v2.py` currently imports private P0 `_POLICY` and independently reconstructs route tuples, and G2c and application `migration_admission.py` hard-code policy-version-v1. Update both consumers for the approved v2 identity and transformed exact route semantics **in this slice**; do not simply accept arbitrary versions or eliminate checks. Replace private `_POLICY` coupling with a reviewed, narrow canonical P0 validation API or equivalent independent recomputation, preserving strict typed fields, exact v1 snapshot and UUID/profile binding and rejection of forged `ScopedPolicyReference`/mutated fields. No caller-supplied routes, self-attested trust or broad monkeypatch may establish authority. G2d accepts only the known new policy identity and recomputed desired values but remains `BLOCKED_UNSUPPORTED` for a valid supported-syntax version (including 6.0.5) because G1 set is empty; malformed/ambiguous input remains `BLOCKED_UNKNOWN`. G2e fixed JSON/source/exit-2 output remains unchanged. Existing policy-v1 references or unrecognized versions never silently pass as v2. Do not change CLI/Legacy implementations.
