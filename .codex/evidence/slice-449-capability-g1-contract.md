# S449-CAPABILITY-G1 — domain-only typed capability contract

Status: PROPOSED pending six-role same-hash review and S3D. This narrowly defines the new installation-scoped capability foundation. It is not a universal Incus version syntax, runtime admission, host protection, caller integration or permission for any host effect. Accepted R67k keeps new-capability support empty until separate version qualification and support-matrix decision. Existing legacy `lxc_node_provider.ensure_node` and Classic fixed configuration remain untouched.

## Typed inputs and closed outcomes

* Intent must be an actual member of the local `IntentKind` enum, exactly `LEGACY_CLASSIC` or `INSTALLATION_SCOPED`. `None`, plain strings (including matching names), foreign enums, booleans, other objects or ambiguous input return `INVALID_INTENT` without coercion.
* `LEGACY_CLASSIC` is identified only by this explicit enum member **and no version** (`None`); a version on that intent is invalid and returns `INVALID_INTENT`. The resulting `LEGACY_CLASSIC` classification is a domain classification, not proof of host readiness or a grant to use the new capability.
* `INSTALLATION_SCOPED` requires a built-in `str` version (no subclasses) using the G1 canonical pattern of three ASCII decimal components `a.b.c`, each either `0` or a nonzero digit followed by digits, total length at most 32 characters. No leading zeros on multi-digit components, signs, whitespace, Unicode digits, missing/extra parts, suffixes or coercions. Missing/non-string/malformed/oversized input returns `INVALID_VERSION`. This intentionally narrow syntax is not an assertion about all valid Incus versions.
* Every syntactically valid scoped version, including `6.0.5`, returns `UNSUPPORTED`. The only support registry is an immutable empty `frozenset`; the public API exposes no registration or mutation operation. No caller can cause a supported result in G1. `INVALID_INTENT`, `INVALID_VERSION`, `UNSUPPORTED` and `LEGACY_CLASSIC` are closed typed results; no parsing exception escapes.

## Required deterministic tests

Verify valid explicit legacy without version and invalid legacy with version; enum identity is strict against plain strings, `None`, other enum classes, booleans and objects. Scoped tests cover missing, non-string, empty, whitespace, signed, leading-zero, extra/missing components, suffix, Unicode digits and >32-character versions, plus canonical `0.0.0`, `6.0.5` and a maximum-length canonical version all returning `UNSUPPORTED`. Verify the set is exactly an immutable empty frozenset, mutation/registration is unavailable, repeated calls cannot add support, and no domain import or execution reaches application, infrastructure, command runner, filesystem or host. Test enum/result classification with no exception leaks and preserve existing legacy tests. This domain-only slice has no runtime caller and proves no guard protects setup, update, upgrade, direct adapter, recovery or cleanup; each future caller needs explicit guard integration and its own negative tests and review.
