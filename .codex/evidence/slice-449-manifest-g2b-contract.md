### Bounded preview-only FD reader

Use the operator-selected local project root once as an **unverified** directory anchor; no supplied subpath is accepted. Compose inputs come exclusively from the fixed project-root paths below. An alternate `TSW_INFRA_ROOT` is not read, consulted or represented by this preview; this result must never imply effective-infrastructure equivalence. Missing project-root assets fail closed. If an invocation explicitly requests or otherwise requires alternate-infrastructure evaluation, reject it before loading rather than silently using project-root assets. Open the root directory read-only and pin its FD. Walk only fixed validated relative components with directory FDs using `O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC`; reject empty, dot, parent or absolute components. Open regular data files using `O_RDONLY|O_NONBLOCK|O_NOFOLLOW|O_CLOEXEC`; validate `fstat` regular-file type before reading. Bound `.tiny-swarm-world/installation/manifest.json` (existing `LOCAL_STATE_DIRECTORY` plus `installation/manifest.json`) to 1 MiB; cap each fixed `infra/config/compose/<fixed-stack>/docker-compose.yml` to 1 MiB, with aggregate max 16 MiB and 16 files, enforcing streaming limits rather than trusting st_size. The current `service_stack_contracts_for_profile("service-access")` contains nine Compose stacks (seven default plus infisical and service-access), therefore one manifest plus nine Compose files = ten files, under the cap. Reject an unexpected stack set or excess count before reading; never widen limits dynamically.

Retain descriptors, compare file and directory identity and metadata before and after reads and revalidate pinned path bindings as specified in tests; reject symlinks, nonregular files, drift, missing/permission errors, truncation/oversize, duplicate paths or uncertain observations. Close every descriptor on all paths. Do not print, log or retain raw paths, data or exception values. This bounded consistency check is not proof against hostile privileged actors, hardlink substitution or ABA, does not establish a trusted project root, and makes no hard CPU/deadline guarantee. Preserve existing `yaml.safe_load` behavior, without claiming protection against arbitrary computationally adversarial YAML.

Add preview-only `PreviewManifestRepository` using this reader and existing `decode_manifest`; its `save` always rejects without effects. Add an optional injected bounded text-reader to existing `NativeComponentCatalog`; default construction and legacy `read_text` behavior remain unchanged, and the preview path uses the reader for all Compose inputs. Do not duplicate catalog parsing or widen default runtime policy. Review actual imports and ports and test both preview and legacy default paths. Unknown/inconsistent assets, unsafe reads or unsupported platform yield fixed blocked output. Assets are operator-local unverified; no catalog provenance, release identity, host safety or live admission is established.

## Fixed safe projection

On valid input output exactly one allowlisted JSON object with `status: PREVIEW`, `source: operator_local_unverified`, `applied: false`, `qualified: false`, `project: UNKNOWN`, `profile: UNKNOWN`, `route: UNKNOWN`, `owner: UNKNOWN`, `swagger_exposure: published|not_applicable`, and `stack_policies` as sorted `{service_id, owner: swarm}` entries derived from G2a. Emit service IDs only after exact membership in the fixed reviewed Classic stack-ID enum `traefik`, `nexus`, `jenkins`, `pulsar`, `sonarqube`, `swagger`, `infisical`, `service-access`, chosen as a fixed reviewed output allowlist, independently of operator-supplied data; syntactic validation or input-provided catalog membership alone is insufficient. Unknown, newly introduced or mismatched IDs fail with the fixed blocked output, never echo the candidate. These are policy labels, not evidence of actual ownership. Do not expose the G2a `v1_snapshot`, host, installation ID, credentials or credential references, configuration, product identities, paths, manifest tokens, diagnostics or raw catalog. Source `operator_local_unverified` is always present on both success and blocked output. Unverified local assets and this preview can never be evidence of catalog authority, release provenance, host safety, live admission or EPIC completion. No automatic migration, profile creation or implicit adoption. Never print the full manifest or snapshot, including on exception.

Missing manifest, invalid/malformed/ambiguous catalog or manifest, I/O/access failures and any unexpected exception emit a single fixed `{"status":"BLOCKED_UNKNOWN","source":"operator_local_unverified","applied":false,"qualified":false}` without exception text or interpolated data and exit 2. The non-success path emits no partial preview, exception, stack trace, raw values or inherited repository diagnostics. Invalid arguments must fail before repository loads or runtime initialization, with the same fixed BLOCKED_UNKNOWN JSON including source marker, exit 2 and no echoed untrusted input; handle argparse's normal echo behavior explicitly. Valid preview exits 0 and does not imply persisted v2, support, service availability or admission. Existing unrelated CLI commands retain their current parsing and output contracts.
