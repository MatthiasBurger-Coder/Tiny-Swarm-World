# S449-MANIFEST-G2B — read-only migration-preview CLI contract

Status PLANNED; no implementation, quality pass or host admission. Baseline `81acdd5c512820b3f69ca193c11d232cb6761ef6` contains G2a, a detached domain preview that includes a sensitive `v1_snapshot`. This slice provides only a sanitized read-only projection; it never implements or accepts persisted v2, adoption, runtime capability support, live qualification or host mutation.

## Route and dependencies

Add exactly `services migration-preview` as a separate read-only workflow; recognize it early in the existing `parse_args` → dispatcher `_run_early_workflow` flow, before `ensure_common_executable_paths`, logger, runtime composition, live consent, provider, network or Docker construction. Existing service/product commands retain behavior. Before loading repositories reject all live, approval, confirmation, recovery, mutation and unrelated flags, duplicate/extra operands and unsupported forms using fixed sanitized errors; never echo argv, paths or exception text. The only permitted argv is exactly `services migration-preview` with no flags or extra operands; output is always JSON. No user-controlled path or host selection. Route this action to its own handler, not `run_lifecycle_inspection`'s generic `inspect()` serialization or `model_dump` of the domain preview.

A new application service uses only the existing `ManifestRepository.load()` and `CatalogRepository.load()` ports and the G2a `preview_migration` domain function. Never invoke `save`, create directories or files, perform adoption, load checkpoint/recovery state or construct runtime services. Existing `ManifestSnapshot` includes token and diagnostics: neither is output or logged. A narrowly composed read-only path may reuse `NativeComponentCatalog` and `JsonManifestRepository` only after verifying their loads and local-state path discovery cause no writes; if not, introduce a separately reviewed read-only adapter/path instead of silently weakening this contract. The existing `build_installation_lifecycle_service` is local composition but its `inspect` serializes complete data and is not an output shortcut. `NativeComponentCatalog` derives IDs from fixed service-stack definitions and reads Compose assets; verify exact reviewed source/asset provenance and no write, and reject mismatches or unknown IDs. A caller-injected or mutable catalog cannot extend the output enum. `JsonManifestRepository.load` and `local_state_file` must also be proven read-only for normal, missing, malformed and permission-failure paths before use; if they cannot, stop and separately review a safe adapter.

## Fixed safe projection

On valid input output exactly one allowlisted JSON object with `status: PREVIEW`, `applied: false`, `qualified: false`, `project: UNKNOWN`, `profile: UNKNOWN`, `route: UNKNOWN`, `owner: UNKNOWN`, `swagger_exposure: published|not_applicable`, and `stack_policies` as sorted `{service_id, owner: swarm}` entries derived from G2a. Emit service IDs only after exact membership in the fixed reviewed Classic stack-ID enum `traefik`, `nexus`, `jenkins`, `pulsar`, `sonarqube`, `swagger`, `infisical`, `service-access`, derived from the exact-source native catalog and locked service-stack definitions; syntactic validation or input-provided catalog membership alone is insufficient. Unknown, newly introduced or mismatched IDs fail with the fixed blocked output, never echo the candidate. These are policy labels, not evidence of actual ownership. Do not expose the G2a `v1_snapshot`, host, installation ID, credentials or credential references, configuration, product identities, paths, manifest tokens, diagnostics or raw catalog. No automatic migration, profile creation or implicit adoption. Never print the full manifest or snapshot, including on exception.

Missing manifest, invalid/malformed/ambiguous catalog or manifest, I/O/access failures and any unexpected exception emit a single fixed `{"status":"BLOCKED_UNKNOWN","applied":false,"qualified":false}` without exception text or interpolated data and exit 2. The non-success path emits no partial preview, exception, stack trace, raw values or inherited repository diagnostics. Invalid arguments must fail before repository loads or runtime initialization, with fixed messages and no echoed untrusted input; handle argparse's normal echo behavior explicitly. Valid preview exits 0 and does not imply persisted v2, support, service availability or admission. Existing unrelated CLI commands retain their current parsing and output contracts.
