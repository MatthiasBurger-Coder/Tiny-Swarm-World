Fixed argv is trusted wsl.exe, selected Ubuntu root, isolated system Python and source-literal bootstrap/code with only a bounded integer TTL. No stdin data/callbacks/commands are written. Literal child emits READY once; monotonic expiry exits3; any input byte exits4; EOF emits CLOSED then exits0. Native launcher PID/start/executable are bound, stderr is bounded, no PID or live process state is written to NTFS/product storage. A failed acknowledgement reports failure, with best-effort cleanup restricted to still-matching owned native launcher. Unknown processes are never killed.

Execute acquires before Observe. Shutdown settles own lease before existing explicit --shutdown. Existing BeginRecovery is the only once-only clock reset. It explicitly renews a remaining lease by overlap, then settles prior ownership without an idle gap. It does not admit an early/unknown nonzero exit. Explicit Recover uses its independent clock from entry; its finally does not reset that clock again.
