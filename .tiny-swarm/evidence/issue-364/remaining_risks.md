# Remaining risks

- Existing installer, root presentation, composition cycles/patch seams, Socat
  command formatting and additive planner debt are documented, not resolved.
- EnsureSwarmStack apply-completion verification is narrower than replica/service
  health; the guide records this shortcut and separate readiness ownership.
- No engine-neutral plugin registry or Podman/Kubernetes runtime is implemented.
- Resolver success alone does not prove backend readiness or live authorization.
- The GitHub guide URL targets main and becomes available only after publication;
  the parent reference states this explicitly. No commit/push/merge is requested.
- Local mocked contracts cannot establish live runtime parity or external quality.
- Evidence stays local until committed/published. Existing ignore rules cover
  the directory; intent-to-add entries make this issue package visible for review.
