link:{handbook-root}README.adoc[Product Handbook] / Part 6

This part owns quality management, security policies, engineering review
policy and audit tracking. Start with
link:{handbook-root}handbook/06-quality-security/qms/qms-light.md[QMS-light],
link:{handbook-root}handbook/06-quality-security/manuals/security-manual.md[the Security Manual] and
link:{handbook-root}handbook/06-quality-security/audit/README.md[the audit evidence index].

The `audit/` registers connect findings to owners, remediation, evidence and
review decisions. They are subordinate to this handbook part, rather than
another documentation master. Part 7 owns linked evidence artifacts and
traceability. Documentation, a planned artifact or an open register is not a
passed verification or a certification.
