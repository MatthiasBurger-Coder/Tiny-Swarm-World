link:{handbook-root}README.adoc[Product Handbook] / Part 2

The link:{handbook-root}handbook/02-architecture/arc42.adoc[arc42 architecture book] is the
architecture part of the Product Handbook. It retains the twelve arc42
sections, detailed analyses, configuration contracts, deployment references,
ADRs and migration plans. The handbook supplies the overall documentation
hierarchy; arc42 supplies the architecture structure within it.

Use link:{handbook-root}handbook/02-architecture/arc42/05_analysis/arch-03-21-resulting-architecture.md[the resulting architecture]
for package ownership and extension guidance. Quality requirements belong in
arc42 section 10, architecture risks in section 11, and the verification
approach in section 8. Operational audit registers belong to Part 6 and
executed evidence belongs to Part 7.

== Source catalogue

Each source below has this part as its primary handbook assignment.
Cross-references from other parts do not change that ownership.
