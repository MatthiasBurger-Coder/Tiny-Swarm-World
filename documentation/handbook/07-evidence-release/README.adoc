= Verification evidence, traceability and releases

ifndef::handbook-root[]
:handbook-root: ../../
endif::[]

link:{handbook-root}README.adoc[Product Handbook] / Part 7

This part owns requirement-to-evidence mappings, review records, release
policies, candidate decisions and dated verification artifacts. Use the
link:{handbook-root}handbook/07-evidence-release/traceability/traceability-matrix.md[traceability matrix],
link:{handbook-root}handbook/07-evidence-release/manuals/live-validation-manual.md[Live Validation Manual]
and link:{handbook-root}handbook/07-evidence-release/release/release-process.md[release process].

Historical reports retain their candidate, source revision, scope and status.
Linking them here does not qualify the current checkout. The
link:{handbook-root}handbook/05-development/process/verification-state-policy.md[verification-state policy]
remains authoritative; planned, blocked, missing and failed evidence stays
separate from executed success. Live runs require explicit authorization and
redacted retained evidence.

Repository-root sources assigned to this part are the
link:{handbook-root}../OPERATIONAL_READINESS_CHECKLIST.md[operational readiness checklist]
and link:{handbook-root}../CHANGELOG.md[product changelog]. Their existing
paths remain the canonical sources.
