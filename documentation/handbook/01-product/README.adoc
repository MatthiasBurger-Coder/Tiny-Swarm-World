link:{handbook-root}README.adoc[Product Handbook] / Part 1

Product purpose and requirement baselines are introduced in
link:{handbook-root}handbook/02-architecture/arc42/01_introduction.adoc[Introduction and goals].
Delivery contracts define the expected bootstrap, lifecycle, installation
manifest and service-selection boundaries. Their requirements do not imply
that every capability has been implemented or qualified.

Start with link:{handbook-root}handbook/01-product/contracts/bootstrap.md[the bootstrap contract]
and link:{handbook-root}handbook/01-product/contracts/lifecycle.md[the lifecycle contract].
Architecture-owned requirement baselines remain indexed in Part 2; their
references here do not create a second source of truth.
