Start with the link:{handbook-root}handbook/05-development/manuals/developer-manual.md[Developer Manual]
and link:{handbook-root}handbook/05-development/manuals/tools-layout.md[directory responsibilities].
Process documents own development workflows, issue completion, verification
states, skill maintenance and agent responsibilities. Workflow records retain
their issue, revision, branch and execution scope; their presence does not
select a workflow for execution.

The repository-level link:{handbook-root}../AGENTS.md[AGENTS.md] and
link:{handbook-root}../QUALITY.md[QUALITY.md] remain the authorities for agent
work and quality checks. Handbook navigation does not override them.

The repository link:{handbook-root}../README.md[entry point] and
link:{handbook-root}../commit_push.md[publication instructions] stay at their
discovery paths. Component-local instructions are reached through
link:{handbook-root}handbook/05-development/manuals/tools-layout.md[the repository and tool layout]
and the source tree; their canonical procedures stay beside the component.
